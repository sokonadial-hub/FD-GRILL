# FD Grill website

Static one-page site for FD Grill, 6732 Elmwood Ave, Philadelphia.

- `index.html`: hero, full menu, hours, location and map
- `css/style.css`: styles
- `js/main.js`: live open/closed status (Philadelphia time) and menu tab highlighting
- `images/`: food photos and logo cut from the printed menu and flyer

No build step. Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, etc.).

To change a price or dish, edit the matching `<li>` in the menu section of `index.html`.
